# 📚 VidyaSetu – ವಿದ್ಯಾಸೇತು

### Learn Better. Grow Smarter. Achieve Together.

**VidyaSetu** is an AI-powered regional-language learning platform designed to make education more accessible, personalised and engaging for students.

Developed for the **Codebenders ACE Builders Hackathon 2026**, VidyaSetu addresses the problem of *The Last-Mile Tutor* by bringing learning support closer to students through regional-language learning, interactive practice and personalised progress tracking.

---

## 🎯 Problem Statement – The Last-Mile Tutor

Many students face difficulties understanding academic concepts because of language barriers, limited access to individual guidance and differences in learning pace.

VidyaSetu aims to bridge this gap by providing a student-friendly learning environment with regional-language support and personalised learning tools.

## 💡 Our Solution

VidyaSetu focuses on **Karnataka State Board Class 8 Mathematics**, with Kannada as the primary regional language and English as an additional language.

The platform brings textbook learning, practice activities, learning progress and student support together in one place.

## ✨ Key Features

### 1. Bilingual Learning Experience
- Kannada and English language options.
- Regional-language learning interface.
- Personalised student profile and learning preferences.

### 2. Textbook and Chapter Learning
- Class 8 Mathematics syllabus with 14 chapters.
- Chapter-wise topics and subtopics.
- Core concepts, explanations and worked examples.
- Practice activities for better understanding.

### 3. Ask Vidya AI
- Personal learning companion interface.
- Mathematics doubt-support interface.
- Text, voice and photo input options.

### 4. Adaptive Practice and Assessments
- Chapter-based practice questions.
- Interactive answer options.
- Quick chapter assessments.
- Learning activities based on mathematical concepts.

### 5. Student Progress and Motivation
- XP points and achievement tracking.
- Learning streaks.
- Chapter completion indicators.
- Overall performance and exam-readiness indicators.
- Leaderboard and achievements.
- Daily challenges and notifications.

### 6. Parent and Teacher Support
- Parent portal for marks and progress.
- Teacher access with an emulated student view.
- Assignment-related interface.
- Student learning progress visibility.

### 7. Additional Learning Support
- Memory and revision section.
- Accessibility options.
- Font-size and appearance settings.
- Help and support section.
